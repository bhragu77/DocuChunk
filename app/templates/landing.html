Platform Features

Everything You Need for
Document Intelligence

From raw PDF to semantic search in minutes. Every layer built for production — and designed for learning.

📄

Smart Document Parsing

Deep extraction from PDF and DOCX files. Preserves page numbers, handles tables, fixes hyphenated line breaks, strips headers and footers automatically.

✂️

Custom Chunking Engine

Three built-in strategies: fixed-size, sentence-aware, and paragraph-based. Configure chunk size and overlap per document. Compare results with the analyser.

🧠

Semantic Embeddings

Powered by HuggingFace's all-MiniLM-L6-v2 — a 384-dimension sentence transformer that captures meaning, not just keywords. Free API tier included.

🗄️

ChromaDB Vector Store

HNSW-indexed vector storage for sub-10ms retrieval. Collections are isolated per user. Embeddings persist on disk across restarts.

🔎

Semantic Search API

Query in natural language. Returns top-K chunks ranked by cosine similarity with source page citations. Filter by document, status, or date range.

📊

Debug Visualisation

UMAP-projected 2D embedding plots reveal how your chunks cluster. Inspect any chunk's raw vector. See cosine similarity to nearest neighbours.

Pipeline

From Upload to Answer
in Six Steps

Every step runs automatically after upload. Watch the status update in real time.

01

Upload Document

Drag and drop any PDF or DOCX. Max 20 MB. File is saved to your private storage bucket with a UUID filename — no path traversal risk.

POST /docs/upload
02

Parse & Clean

PyMuPDF extracts text page by page. The cleaner fixes unicode ligatures, hyphenated breaks, page number noise, and excessive whitespace.

Background Task
03

Intelligent Chunking

Your custom chunker splits text into overlapping segments. Choose between fixed, sentence-aware, or paragraph strategies. Tune size and overlap.

GET /chunks/analyse
04

Generate Embeddings

Each chunk is encoded into a 384-dimension vector via HuggingFace free API. Batched in groups of 32 with exponential backoff retry.

POST /embed/trigger
05

Store in ChromaDB

Vectors are upserted into your personal HNSW index. Each entry carries full metadata: page, chunk index, strategy, token count.

ChromaDB HNSW
06

Search & Generate

Query in plain English. Top-K relevant chunks are retrieved by cosine similarity and fed to an LLM for a cited, grounded answer.

POST /generate/answer
